# Building Images

Put building and question photos in this folder.

Use stable file names that match backend seed `imageUrl` values:

```txt
oggb-cover.jpg
oggb-01.jpg
oggb-02.jpg
clocktower-cover.jpg
clocktower-01.jpg
```

The backend stores paths only, for example:

```txt
/images/buildings/oggb-cover.jpg
/images/buildings/oggb-01.jpg
```

Do not put image binary data in backend JSON seed files.
